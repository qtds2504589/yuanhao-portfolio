IMON 品牌店

IMON RETAIL STORE SCENE SYSTEM
RETAIL STORE · SCENE-BUILT NATURE DISPLAY

项目角色 / PROJECT ROLE

以「野无界，萌于心」为品牌基调，为 imon 打造可复制的门店场景系统——
6×2m / 4×5m 的限定场地内，用树皮立柱、木纹货架与动物 IP 造景还原自然场景。

Building a replicable in-store scene system for imon — nature restored within compact retail footprints.

02 / 品牌策略
BRAND STRATEGY

「野」是旷野自然的表达，「萌」是自我接纳的认可——品牌基调由此界定。
关键词：场景还原 · 故事情节 · 标准化，为复制店建立可复用的设计模板。
"Wild" speaks of nature, "Cute" of self-acceptance — a replicable template for future stores.

场景定位 / SCENE POSITIONING

根据不同应用场景，以毛绒动物为主 IP 设计自然场景，在满足铺货的同时增加自然氛围。

  1. 016×2m 场景 / Compact Scene
  2. 024×5m 场景 / Standard Scene
  3. 03靠墙店 / Wall-mounted
  4. 04集合店 / Gathering Store
  5. 05复合店 / Complex Store

03 / 场景营造
SCENE STORYTELLING

树洞里的松鼠表达「温暖」，悬崖峭壁上的狮子表达「王者风范」，魔法树中冲出的金刚表达「力量」——
打动人心的永远是故事，是场景里的情节。
Squirrel in the tree hole = warmth; lion on the cliff = majesty; gorilla from the magic tree = power.
